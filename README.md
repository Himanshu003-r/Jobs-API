# A jobs portal api 

  This project features CRUD (Create Read Update Delete) operation which are crucial in any server to perform action on database.
  The Jobs model ensures creates new jobs with reference to User model.


# Packages to install
  
  mongoose - ```npm i mongoose```
  
  express - ```npm i express``` 
  
  bcryptjs - ```npm i bcryptjs```
  
  jsonwebtoken - ```npm i jsonwebtoken```
  
  dotenv - ```npm i dotenv```
